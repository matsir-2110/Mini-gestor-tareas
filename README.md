# Mini-gestor-tareas
Gestor de tareas (to-do list)

El programa creado tiene como fin que el usuario pueda:

            . Anotar sus tareas y darle una descripción.
            
            . Marcar una tarea como completada
            
            . Eliminar una tarea
            
            . Listar todas las tareas
